# 레벨 명세 v2 · 학교 P07~P09

> [공통 계약](../GDD.md) · 미구현 설계입니다. 학교 전체에 ‘안 보면 바뀜’을 적용하지 않습니다.

## 정상 기준과 정보 표시

복도 폭 3 m, 교실 9×7.5 m, 천장 2.7 m를 조립 기준으로 합니다. 바닥·문턱·점검 손잡이는 어두운 곳에서도 읽혀야 합니다. 교실 번호는 분위기용이며 필수 판정은 도형·설비 반응으로 가능합니다. 벽의 전선관과 CCTV 배선은 실제 기능 관계를 따릅니다.

실시간 화면에는 연결된 케이블 모양과 가동 표시, 보관 화면에는 고정된 사진 모서리 표시를 둡니다. 글자를 읽지 않아도 차이를 알아낼 수 있으나, 아이콘만 보고 전부 풀리는 것은 아닙니다. 실험으로 정보의 출처·좌우 대응을 확인합니다. REC 빨간 불은 실제 작동 사실이며 거짓 연출에 쓰지 않습니다.

## P07 · 멈춘 화면의 시험등 (`v2_p07`)

### 목표·공간

방송실에서 막힌 복도 분기 중 실제로 계단까지 이어지는 쪽을 열어야 합니다. 왼쪽 분기 L은 내려간 방화판으로 막혀 있고 오른쪽 R은 계단까지 이어집니다. 현장 전체는 방송실에서 직접 보이지 않습니다. 화면 둘은 실시간, 하나는 보관 영상이며, R 카메라 앞에는 점검용 거울이 있어 화면의 좌우가 뒤집힙니다.

```text
방송실 [화면 1 / 2 / 3] [시험등 L·R] [차광판 L·R] [분기 선택 손잡이]
                    ├— L: 닫힌 방화판, 정상 직접 카메라
                    └— R: 열린 계단, 거울 경유 카메라
```

### 정보·상태 계약

| 화면 | 실제 출처 | 시험 반응 |
|---|---|---|
| 1 | 현재 L, 직접 영상 | L 시험등·차광판만 반응 |
| 2 | 과거 R의 보관 화면, 계단 앞이 닫혀 있음 | 현재 어떤 입력에도 반응하지 않음 |
| 3 | 현재 R, 거울 경유 | R 시험등·차광판 반응, 비대칭 ㄱ자 틀이 좌우 반전 |

화면의 틀과 현재 시험등 모양은 같은 공간을 가리키지만 화면 번호는 카메라 이름과 동일하다고 보장하지 않습니다. 조작대 L에는 원 모양, R에는 삼각 모양 시험등이 있습니다. 직접 보이는 해당 설비의 정비 사진과 ㄱ자 틀은 좌우 대응의 독립 기준입니다. 분기 선택기는 L/R 중 하나의 입구 차단봉만 엽니다. 열린 상태는 계속 유지됩니다.

### 가설·실험·해법

1. 화면 2가 현재라고 믿으면 R이 막혔다고 판단하게 됩니다. 시험등을 바꿔도 화면 2는 변하지 않고, 보관 모서리 표시가 출처를 설명합니다.
2. 화면 3에서 계단이 왼쪽에 있으니 L이라고 추정할 수 있습니다. R 시험등·차광판이 반응하고 ㄱ자 틀이 반전됐음을 보면 이 가설을 기각합니다.
3. 원 시험등 ON/OFF, 삼각 시험등 ON/OFF 또는 차광판 열기/닫기 중 서로 구별 가능한 두 입력을 골라 비교합니다. 빠른 점멸 기억 시험은 없습니다. 입력은 유지됩니다.
4. 현재 R이 통행 가능함을 확인하고 선택기를 R로 둡니다. R 입구로 가서 계단을 통과합니다.

대안: 현장 가까운 점검 창에서 R의 실제 계단을 확인하고 방송실에 돌아와 열어도 됩니다. 짧은 우회 관찰이며 필수 경로보다 빠르지는 않지만 정직한 다른 풀이입니다. 화면을 무조건 믿게 강제하지 않습니다.

### 오답·복구·힌트

L을 열면 내려간 실제 방화판까지 안전하게 걸어가 볼 수 있습니다. 사망·기습·초기화 없이 현장의 상태를 추가로 배웁니다. 선택기는 언제든 바꿀 수 있고 입력에 소모 비용은 없습니다. 시험등은 퍼즐 완료와 관계없는 관찰 수단입니다.

힌트 ① 시험등과 화면 모서리 표시. ② “조작에 반응하는 화면은 어느 것인가요?” ③ 현재 화면과 ㄱ자 정비 사진을 비교하도록 유도. 힌트가 정답 화면 번호만 말하지 않습니다.

### 공포 `H-P07`·구현·평가

현재 화면에서 시험등이 꺼졌는데 보관 화면에서는 계속 켜져 있습니다. 화면 2는 처음부터 같은 보관 자료이며, 플레이어를 속이려고 실시간에서 몰래 보관으로 바뀌지 않습니다. 별도 추가 큐 없이 정상 시험음과 화면의 불일치가 연출입니다. 소리와 상태는 재현 가능하고 화면을 안 봐도 퍼즐 상태가 바뀌지 않습니다.

필요 기능: 실제 카메라 뷰 2개, 보관 이미지 1개, 거울 경유 영상의 좌우 대응, 시험등·차광판·분기 선택기. 비용 중간. 낮은 품질에서도 정보 대응은 유지합니다. “선명함=현재”, “화면 왼쪽=실제 왼쪽”이라는 가설을 각각 검증했는지 봅니다. 보관 영상의 정확한 버전을 기억해야 하는 문제는 아닙니다.

## P08 · 남겨 둘 복도 (`v2_p08`)

### 목표·배치

구조 변경 손잡이는 복도를 두 배치로 바꿉니다. 배치 0에는 건널 다리가 있지만 출구가 막혀 있고, 배치 1에는 출구가 있지만 다리가 없습니다. 카메라로 다리 부분만 유지하면 나머지를 바꿀 수 있습니다. **눈앞의 출구를 찍는 것과 필요한 통행 조건을 남기는 것은 다릅니다.**

```text
입구/변경 손잡이 — 4 m 안전 구간 — [구역 A: 6 m 다리] — [구역 B: 출구 벽]
  카메라 선택대: OFF / 넓게(A+B) / 좁게 A / 좁게 B
```

### 유한 상태표

| 요청 배치 | A: 다리 | B: 출구 |
|---|---|---|
| 0 (초기) | 있음 | 막힘 |
| 1 | 없음 | 열림 |

REC OFF가 초기입니다. 카메라 방향은 네 정지점 중 고르고 화면의 실제 촬영 경계·바닥 점검선으로 포함 구역을 봅니다. REC를 켠 순간 포함된 구역의 현재 구조 상태를 유지합니다. 구조 손잡이를 1로 바꾸면 **고정되지 않은 구역만** 요청 상태로 바뀝니다. 이미 고정한 구역을 다시 촬영해도 자동 순환하지 않습니다.

| 0에서 시작해 요청 1 | 실제 A/B | 결과 |
|---|---|---|
| OFF | 없음/열림 | 다리가 없어 건널 수 없음 |
| 넓게 A+B, REC | 있음/막힘 | 출구까지 고정해 열리지 않음 |
| A만, REC | 있음/열림 | 통과 가능 |
| B만, REC | 없음/막힘 | 둘 다 불리한 상태 |

### 가설·실험·해법

처음에는 “카메라가 켜지면 전체가 멈춘다” 또는 “출구를 찍어야 열린다”고 추측할 수 있습니다. 넓은 범위와 B만의 시험으로 각각 다른 결과를 얻습니다. 카메라를 끄고 요청을 0으로 되돌리면 같은 기준에서 다시 비교할 수 있습니다.

표준 해법: 요청 0 확인 → A만 촬영 → REC ON → 요청 1 → A 다리와 B 열린 출구를 함께 확인 → 통과. 한 번 넓게 고정했다가 카메라를 해제하고 다시 맞춰도 됩니다. 최종 조건은 `A=있음 && B=열림`이며 행동 횟수는 검사하지 않습니다.

### 안전·복구·힌트

REC를 끄면 보류돼 있던 요청 상태가 적용됩니다. 몸이 구조 구역 안에 있으면 안전 발판까지 벗어날 때 적용합니다. 입구 손잡이는 다리에서 4 m 떨어져 있어 몸으로 다리를 점유한 채 조작하는 방식이 기본 해법을 우회하지 않습니다. 점유 보호는 다리 위 플레이어를 떨어뜨리지 않는 기능이지 원격 조작 도구가 아닙니다.

다리가 없는 상태에서도 입구의 조작대는 계속 접근 가능합니다. 필수 경로에 낙하 구간을 뛰어넘어야 하는 곳은 없습니다. 초기화는 요청 0·REC OFF·안전 입구입니다. 저장에는 요청 배치와 A/B의 실제 유지 상태를 따로 남깁니다.

힌트 ① A/B 점검 경계. ② “화면에 들어오는 부분과 바뀌지 않는 부분을 비교해 보세요.” ③ “출구까지 남겨 둘 필요가 있을까요?”

### 공포 `H-P08`·구현·평가

A를 유지하고 나머지를 바꾸면 다리의 낡은 바닥선은 그대로인데 주변 교실 깊이가 달라집니다. 카메라를 돌리게 강제하지 않고 요청한 변화가 보이는 곳에서 천천히 반영됩니다. 구조가 접속 틀 안에서 교체되는 동안 통행을 잠깐 보류하되, 빨리 통과할 필요는 없습니다. 추가 음향은 첫 부분 유지 성공에 한 번, 변화 정지 시 종료합니다.

필요 기능: 두 구조 구역·두 배치, 카메라 범위와 REC, 유지 상태, 점유 보호. 비용 중간~높음. 범용 시선 판정이나 모든 사물의 변이 시스템은 만들지 않습니다. 해법을 아는 사람이 “A를 남긴다”는 관계로 설명하는지 봅니다. 카메라 선택지만 무작정 순회해 푼 경우 촬영 범위와 구조 변화의 대응을 보강합니다.

## P09 · 두 이름의 교실 (`v2_p09`)

### 목표·공간·초기 조건

비상 승강기 전원을 확보하기 위해 일반 부하 X·Y를 끄고 비상 공급 Z는 켜 둬야 합니다. 문 이름은 네 개 A/B/C/D지만 A와 C는 공간 접속으로 같은 교실 X의 앞뒤입니다. B는 교실 Y, D는 비상 설비실 Z입니다. **표찰 네 개를 실제 방 네 개로 세면 같은 회로를 다시 켜 버립니다.**

```text
짧은 공용 관찰 복도
  A → 교실 X ← C       B → 교실 Y       D → 비상실 Z
  └ 같은 시험등·책상 흠집·상태 ┘
```

A/C는 같은 원격 접촉기의 상태를 바꾸는 두 순간 누름 버튼입니다. 각 버튼 옆 ON/OFF 기계식 표시도 같은 X 상태를 보여 줍니다. 물리적 차단기 두 개가 서로 다른 위치로 거짓 표시되는 구조는 아닙니다. 초기 `X=ON, Y=ON, Z=ON`, 승강기 전원 조건은 `!X && !Y && Z`입니다. 전력 흐름 도형이 일반 부하 두 갈래와 비상 공급 하나를 보여 주며 전기 계산·한글 독해는 필요 없습니다.

### 가설·실험·해법

1. “문 하나당 다른 방”이라면 A를 눌러도 C의 등은 그대로여야 합니다. 실제로 A를 누르면 C 안의 동일한 책상 흠집 옆 등이 같이 꺼지고 C 버튼의 표시도 OFF가 됩니다.
2. C를 다시 누르면 A쪽도 켜집니다. 두 출입점이 같은 상태에 접근한다는 것을 확인합니다. P01의 동일성을 방 전체에 확장하는 짧은 확인 문제입니다.
3. B는 별도 반응이고 D를 끄면 승강기 공급 표시까지 꺼집니다. 조작 결과는 공용 복도에서 비교 가능합니다.
4. 해법: A 또는 C로 X OFF → B로 Y OFF → Z ON 유지 → 승강기 탑승.
5. 대안: 전부 눌렀다가 공급 흐름을 보며 Z와 X를 고쳐도 됩니다. X를 어느 출입점에서 껐는지는 중요하지 않습니다.

### 오답·복구·힌트

같은 X를 두 번 바꾸면 원래 상태가 되며 Y에는 영향이 없습니다. 네 버튼을 다 누르면 Z가 꺼져 모터가 켜지지 않습니다. 모든 버튼은 복도에서 접근 가능하고 어떤 조작도 통로를 잠그지 않습니다. 비상등은 별도 안전 조명이라 Z를 꺼도 플레이 화면이 암전되지 않습니다. 초기화는 세 회로 ON입니다.

힌트 ① A/C의 동일한 책상 흠집. ② A 입력 때 C의 기계식 표시 변화. ③ “이름표 수와 실제 회로 수가 같은지 확인해 보세요.”

### 공포 `H-P09`·구현·평가

한 교실의 양쪽 출입문이 서로 다른 학년 표찰을 달고 있습니다. 직접 입력하면 두 ‘다른 기억’이 같은 방으로 반응합니다. 표찰은 조작 중 몰래 바꾸지 않습니다. X를 처음 끌 때 두 공간의 전기음이 동시에 사라지고 이후에는 정상 조작음만 납니다. 실루엣·교실 안의 사람 소리는 없습니다.

필요 기능: X의 표현 두 개, 독립 Y/Z, 입력·전원 흐름 표시. 비용 낮음. 새로운 고난도 퍼즐이 아니라 정리와 귀환 준비입니다. 설명 가능한 새 발견이 이미 P01과 완전히 같아 지루하다고 판단되면 별도 방으로 늘리지 않고 이동 구간의 짧은 설비 조작으로 축소합니다. 플레이타임 확보를 위해 억지로 유지하지 않습니다.
