# 레벨 명세 v2 · 귀환 P10~P11

> [공통 계약](../GDD.md) · 미구현 설계입니다. 귀환에는 새 공간 문법을 추가하지 않습니다.
> P10은 P03의 배선과 P08의 구조 유지, P11은 P01·P07·P09의 개체·출처 검증을 사용합니다.

## 돌아왔다는 증거

P01의 꺾인 레일 눈금과 정산소 창 방향을 재사용합니다. 형태를 알아볼 수 있어야 하므로 전부 침수시키거나 조명을 대부분 끄지 않습니다. 통로 가장자리의 얕은 물은 반사와 경계의 대비를 위해서만 쓰고 새로운 수영 퍼즐로 만들지 않습니다. 첫 정상 조작음과 비교할 수 있게 같은 정비대 소리·차단기 소리를 사용합니다.

## P10 · 길과 전선은 다르게 (`v2_p10`)

### 목표·배치

정문 앞 전동 문을 열고 통과해야 합니다. 걷는 통로 W가 열린 배치에서는 접속 G를 거친 배선 길이가 9 m로 늘어 6 m 케이블이 닿지 않습니다. 배선이 5 m인 배치에서는 W가 벽으로 막힙니다. **몸의 길과 전선의 길이 동시에 성립해야 합니다.**

```text
릴/카메라/구조 손잡이 — G: 배선 접속부 ≈ 소켓
  └———————— W: 보행 통로 — 전동 문 — 정문 전실
카메라 정지점: G / W / 넓게 G+W / OFF
```

배선 릴·고리의 조작과 접속 틀은 P03과 같습니다. 전동 문은 P03 셔터와 달리 **전원 유지가 필요한 스프링 복귀문**입니다. 노출된 복귀 스프링·유지 전원 그림으로 차이를 먼저 보여 줍니다. 이 차이를 숨긴 예외로 사용하지 않습니다.

### 구조·상태표

| 요청 배치 | G의 배선 길이 | W |
|---|---|---|
| 0 | 5 m, 케이블 도달 | 벽으로 막힘 |
| 1 (초기) | 9 m, 길이 부족 | 열림 |

REC와 구조 유지 계약은 P08과 동일합니다. 현재 상태를 포착한 구역만 유지합니다. 요청을 바꾼다고 카메라가 새 상태를 자동 촬영하지 않습니다.

| 배치 1에서 촬영 후 요청 0 | 실제 G/W | 결과 |
|---|---|---|
| OFF | 5 m/막힘 | 연결 가능, 몸은 못 감 |
| G만 REC | 9 m/막힘 | 둘 다 불리함 |
| W만 REC | 5 m/열림 | 배선 연결 후 통과 가능 |
| G+W REC | 9 m/열림 | 몸은 가지만 전원 부족 |

### 가설·실험·해법

- 처음 W를 따라 걸으면 전동 문이 꺼져 있습니다. 길이 띠로 9 m 경로가 부족함을 확인합니다.
- 요청을 0으로 바꾸면 5 m 배선 경로는 생기지만 W가 막힙니다. 연결만 성공했다고 목표를 달성한 것은 아닙니다.
- 배선 G를 유지해야 한다는 가설로 초기 G=9 m를 찍으면 틀린 상태를 보존합니다. **어떤 구역의 어떤 상태를 남기는가**를 함께 판단해야 합니다.
- 표준 해법: 요청 1로 W 열림 → W만 촬영하고 REC ON → 요청 0 → G=5 m/W=열림 확인 → 케이블 5 m 경로 연결 → 전동 문 통과.
- 대안: 먼저 요청 0에서 연결 가능성을 확인한 뒤 1로 복구하고 W를 유지해도 됩니다. 최종 결과가 맞으면 카메라 조작·케이블 연결의 세부 순서는 강제하지 않습니다.

### 연결의 지속·오답·복구

연결 후 G가 9 m로 바뀌면 길이 제한 때문에 소켓 연결이 해제됩니다. 케이블이 끊어지거나 소모되지는 않고 마지막 안전 고리로 회수됩니다. 변화 예고선이 연결 불가를 먼저 표시하고 평범한 커넥터 해제음으로 결과를 전달합니다. 상태 변경·길이 재계산·전원 반영은 한 번의 안정 상태 갱신으로 처리합니다.

W가 막혀도 릴·카메라·손잡이는 입구 안전 구역에 남습니다. 문 아래 점유 중에는 스프링 복귀를 보류하고 지나간 뒤 정문 전실의 걸쇠가 문을 열어 둡니다. 카메라 해제나 연결 손실로 사람을 가두지 않습니다. 초기화는 요청 1, 유지 없음, 케이블 회수, 입구입니다.

힌트 ① W와 G의 서로 다른 점검 경계. ② 길이 띠와 촬영 범위를 비교. ③ “짧은 연결을 남기는 방법 외에, 열린 통로를 남길 수도 있습니다.”

### 공포 `H-P10`·구현·평가

같은 주차장인데 고정된 보행 통로 뒤쪽으로 배선이 다른 공간의 길이를 따라 사라집니다. 조작의 정답 여부와 상관없이 요청한 구조만 바뀝니다. 처음 두 구역의 상태가 분리되면 1장의 형광등 소리와 학교의 짧은 잔향이 서로 다른 방향에서 겹칩니다. 이 추가 큐는 한 번이고 구조 안정 시 종료합니다. 소리로 문이 열렸다고 거짓 표시하지 않습니다.

필요 기능은 P03·P08 재사용과 연결 무효화 처리입니다. 새 시스템 추가 비용보다 결합 비용이 큰 구간입니다. 관찰할 것은 “어떤 대상을 찍는다”가 아니라 “남길 상태와 바꿀 상태를 나눈다”는 설명입니다. 해법을 안 뒤 이동·재설정만 오래 걸리면 조작대와 관찰 지점 간 거리를 줄입니다.

## P11 · 마지막 퇴장 (`v2_p11`)

### 목표·공간

정문 전실의 퇴장 확인기는 미처리 입장 기록 하나를 가지고 있습니다. 출구 앞 경계 P를 한 번 지나면 해제돼야 하지만, 같은 경계를 나타내는 B·C 두 채널이 각각 퇴장으로 기록돼 -1이 됩니다. 과거 두 구역으로 관리되던 접속이 현재 하나의 경계가 된 탓입니다. **숫자를 억지로 맞추거나 가상의 사람을 찾지 않고, 같은 사건이 두 번 측정됨을 고칩니다.**

```text
전실 입구 A(독립 경계) — 조작대/시험 모형 — P(한 경계의 B·C 표현) — 정문
                           └ 측면 유리로 B·C 감지선과 같은 표식 확인
```

이 숫자는 건물 안 사람의 실시간 수가 아니라 이 전실의 **미처리 입장 기록**입니다. 사람이 안에 있으니 0이 불가능하다는 함정은 만들지 않습니다. 정문 앞 감지선을 지나는 순간 퇴장 처리를 완료하고 문이 열리는 정상 개방 순서입니다.

### 상태·표시·입력

| 항목 | 초기값·동작 |
|---|---|
| `pending` | 1, 현재 전실에 들어온 입장 기록 |
| `sensor_group` | A/B/C 각각 독립 |
| 경계 P 통과 | B·C 채널이 같은 실제 사건 ID로 반응 |
| 묶음 선택 | 없음 / A+B / A+C / B+C 중 하나 |
| 같은 그룹의 같은 사건 | 한 번만 퇴장 처리 |
| 문 해제 | 실제 통과 처리 후 `pending == 0` |
| 정정 손잡이 | `pending=1`과 통과 전 안전 지점 복구, 선택 묶음은 유지 |

조작대에는 세 감지선의 도형, 입력 펄스 표시, 시험용 이동 표식이 있습니다. 시험 레버는 표식을 A 경계 또는 P 경계에 한 번 통과시킵니다. 시험 기록은 실기록과 테두리·도형이 다른 별도 창에 나오며 실제 `pending`을 바꾸지 않습니다. 시험 뒤 결과가 남아 빨리 깜빡이는 빛을 기억할 필요가 없습니다.

### 가설·실험·해법

1. “미처리 기록 둘이 더 있다”는 가설 대신 채널 출처를 확인할 수 있도록 감지선의 실제 위치와 같은 모서리 표식을 보여 줍니다. 사람을 찾는 소리나 형체는 없습니다.
2. A에 시험 표식을 보내면 A만 반응합니다. P에 보내면 한 표식의 한 번 통과에 B·C가 함께 반응합니다. 유리창으로 두 표현이 같은 선임을 확인합니다. 단순 동시 발생만으로 동일성을 주장하지 않습니다.
3. B+C를 묶고 P 시험을 다시 하면 시험 창에는 한 사건만 기록됩니다. A 시험은 여전히 독립 반응합니다.
4. 실제로 P 감지선까지 걸어가면 기록 1→0, 정문이 정상 속도로 열립니다. 통과해 에필로그로 나갑니다.

대안: P를 먼저 지나 오류 -1을 직접 보고 정정 손잡이로 복구한 뒤 묶어도 됩니다. 조작대의 시험만으로 알아낸 풀이와 실제 실패에서 배운 풀이를 모두 허용합니다. 두 번 앞뒤로 걸어 숫자를 상쇄하는 방법은 없습니다. 퇴장 감지선은 전실을 나가는 방향의 최초 통과만 기록하고 복귀는 새로운 입장으로 세지 않습니다. 방향은 정상 출입 센서의 역할이며 공간 행선지를 뒤집는 규칙은 아닙니다.

### 오답·복구·힌트

묶음 없음이나 A+B/A+C에서는 P의 B·C가 두 다른 그룹으로 처리돼 -1이 됩니다. 같은 사건의 채널을 모두 집계한 뒤 최종값으로 문을 판정하므로 중간 0에서 잠깐 열리지 않습니다. 진단 표시만 1→0→-1의 두 펄스를 남깁니다. 정정 손잡이는 P 전면에서 항상 접근 가능하며 1로 되돌립니다. 정정만 반복해서 0을 만들 수는 없습니다.

이미 문이 열리고 통과했다면 기계식 걸쇠가 잡아 설정을 바꿔도 사람 위로 닫히지 않습니다. 초기화는 입장 기록 1·그룹 독립·전실 입구입니다. 이전 퍼즐 완료를 지우지 않습니다.

힌트 ① P의 같은 모서리 표식과 두 채널. ② “한 표식이 몇 번 통과했고, 기록은 몇 번 생겼나요?” ③ “같은 사건의 두 표현을 한 묶음으로 처리해 보세요.”

### 공포 `H-P11`·구현·평가

같은 감지음이 두 주소에서 울리고 기록만 둘 생깁니다. 무엇인가 더 있다는 암시 대신 **기록이 공간을 잘못 나누고 있다는 불편함**을 완성합니다. 정답 뒤 카운터를 몰래 1로 바꾸거나 마지막 문 뒤에서 발소리를 내지 않습니다. 최종 해제음은 프롤로그의 차단기 개방음과 같은 계열입니다. 추가 큐 없이 실험 자체가 연출이며 조작마다 재현됩니다.

필요 기능: 출입 사건 ID, 그룹별 중복 제거, 시험/실기록 분리, 정정·안전 걸쇠. 비용 중간. 새로운 규칙 암기 대신 동일성을 사건에 적용했는지 확인합니다. 문 앞에서 같은 길을 여러 번 왕복하게 만들지 않습니다. 답을 알면 시험 한 번과 묶음 선택 후 바로 나갈 수 있습니다.

## 에필로그

프롤로그에서 보았던 건너편 인도·정문·가로등이 이른 아침에 다시 보입니다. 철거 예고와 옛 안내도에 적힌 구역 구분이 다릅니다. 원인을 설명하는 방송·대사·정체 공개는 없습니다. 추가 흔적 수와 관계없이 모두 이 장면에 도달합니다. 생활 소리는 자연스럽게 돌아오고, 크레딧은 사용자가 준비됐을 때 진행할 수 있습니다. 숨은 괴물·추격·마지막 점프 스케어는 없습니다.
