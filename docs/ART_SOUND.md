# 아트·사운드 지침 v2 — 정상적인 장소에 불가능한 관계

> [기획 기준](GDD.md) · [조사 근거](RESEARCH.md) · 아래 수치는 제작 시작값이며 시청각 검증 결과가 아닙니다.

## 1. 선결론

**무서운 장식을 더하는 대신, 정상적인 장소를 정확하게 만든 뒤 관계 하나를 어긋나게 합니다.** 한국의 1990년대 말 복합센터가 공포의 주인공입니다. 사람·생물·형체·마네킹·흔들리는 인체 그림자·추격 발소리는 사용하지 않습니다.

표면을 피·녹·낙서로 채우지 않습니다. 청소된 면, 오래 닳은 작업선, 손이 닿은 손잡이, 같은 규격이 길게 반복되는 천장이 기준입니다. 모든 것이 낡고 망가져 있으면 정상과 이상의 차이를 읽을 수 없습니다. 극단적인 어둠·화면 노이즈를 퍼즐 난도의 대용으로 삼지 않습니다.

### 공간의 세 층

| 층 | 반드시 보일 것 | 바뀌어도 되는 것 |
|---|---|---|
| 판단 기준 | 접속 틀·작동 표시·눈금·안전 발판 | 정답과 무관한 설정 변경으로 감추면 안 됨 |
| 생활의 흔적 | 벗겨진 손잡이 도장·수리 자국·시설 간판 | 장별 사용 시기의 차이 |
| 위화감 | 길이·소리 출처·표현 개수·기록의 대응 | 명세된 사건의 결과만 변경 |

## 3. 같은 것·다른 것을 그리는 규칙

### 동일한 개체의 두 표현

공유 물체에는 임의 번호보다 구체적인 사용 흔적을 복제합니다. P01 2호기 팔레트의 꺾인 노랑 테두리와 용접 흠집, P02 덮개판 D-7의 사선 무늬는 모든 표현에서 좌표에 맞게 유지합니다. 주변 벽은 달라도 이 특징의 대응은 바뀌지 않습니다. 모든 모델을 노란 테이프로 두르지 않습니다.

### 접속 틀

J 개구부에는 단단한 외곽 프레임, 이어지는 모서리 홈, 방향을 비교할 비대칭 ㄱ자 표식을 둡니다. 프레임 하나의 특징만으로 연결을 확정하지 않으며 실험 결과와 결합해 읽습니다. 일반 문은 정상 문틀이고, 반사창에는 유리 두께·프레임·차광판이 있습니다. 물속 접속도 타일 색이 아닌 틀의 대응으로 구분합니다.

### 기록과 실제

보관 화면은 사진 모서리·저장 표시가 고정돼 있고 시험 입력에 반응하지 않습니다. 실시간 화면은 실제 시험등·차광판에 반응합니다. 어느 쪽도 게임의 UI 오류처럼 깜빡이지 않습니다. REC는 실제 구조 유지 기능이 활성화됐을 때만 켜집니다. 실시간 연결 표시와 REC 기능 표시를 하나의 빨간 점으로 합치지 않습니다.

### 유지 구역

P08·P10의 구조 경계는 바닥의 점검선과 천장의 같은 접합선으로 이어집니다. 촬영 범위 미리보기는 모니터 안에만 보조 표시하고 세계를 형광 색으로 칠하지 않습니다. 색 없이도 구역의 닫힌 경계를 따라갈 수 있어야 합니다. 유지된 부분과 바뀐 부분의 경계에서 물리적 틈이나 밟을 수 없는 경사면이 생기지 않게 조립합니다.

## 4. 연출 큐 시트

구체 입력·상태는 각 레벨 명세가 우선입니다. 추가 큐가 기능 피드백을 바꾸면 안 됩니다. `한 번` 큐는 안정 상태 저장 시 재생 완료도 저장합니다. 상태 복구 중에는 과거 큐를 재생하지 않습니다.

| 큐 | 트리거 | 화면·소리 | 종료·반복 |
|---|---|---|---|
| H-P01 | 2호기 최초 이동 | 앞뒤 피트의 같은 승강음, 먼 쪽에 긴 울림 | 정지 시 종료, 1회 |
| H-P02 | 덮개 첫 조작 | 덮개와 출구판의 같은 소리, 눈앞에서 닫히는 출구 | 정지 시 종료, 1회 |
| H-P03 | 케이블 첫 접속 | 먼 β에서 릴 마찰 끝이 남 | 소켓 점등, 추가 큐 1회 |
| H-P04 | 최초 급수 | 멀리 난 B 수조창과 가까운 A 수면의 같은 수위선 | 수위 안정, 1회 |
| H-P05 | 시험 수문·배수 작동 | C 청음구 음량과 B 노선의 반응 불일치 | 작동 종료, 기능음이므로 매번 동일 |
| H-P06 | 첫 표식 왕복·첫 도킹 | 떨어진 물결의 대응, 계단 걸쇠의 정상 소리 | 각 동작 종료, 추가 강조 각 1회 |
| H-P07 | 시험등·차광판 입력 | 현재와 보관 화면의 차이 | 추가 큐 없음, 상태에 따라 재현 |
| H-P08 | 최초 부분 유지 성공 | 다리 바닥선은 남고 주변 깊이가 바뀜 | 구조 안정, 추가 강조 1회 |
| H-P09 | X 최초 차단 | 두 주소의 전기음 동시 소거 | 안정 시, 이후 정상 피드백 |
| H-P10 | 최초 구조 상태 분리 | 주차장 지속음과 학교 짧은 잔향의 공존 | 안정 시, 추가 강조 1회 |
| H-P11 | 시험/실제 통과 | 하나의 사건에 두 감지음·기록, 정정 후 하나 | 기능음만 재현, 최종 뒤집기 없음 |

플레이어가 연출을 보지 못해도 해당 증거를 재실험할 수 있습니다. “돌아봤는가”를 필수 해법 조건으로 추가하지 않습니다. 정답을 놓치지 않으려고 카메라를 강제 회전하거나 입력을 잠그지 않습니다.

## 5. 사운드 설계

### 역할별 분리

향후 오디오 버스는 Master / Ambience / Interaction / Evidence / UI로 구분합니다. Evidence는 실험 결과·기계식 표시의 소리입니다. 이것을 꾸미기용 Ambience와 섞어 다른 주소에서 무작위로 재생하지 않습니다. 현 구현의 버스 구성과 같다는 뜻은 아닙니다.

- 정상 소리: 발소리, 손잡이, 레일, 스프링, 릴, 밸브, 부표, 접촉기, 출입 감지기.
- 공간 소리: 환기·안정기·여과기·관의 공명·창밖 도로. 원인이 있는 지속음으로 만듭니다.
- 이상은 같은 소리의 위치·차폐·동시성에서 만듭니다. 새 괴물 소리를 추가하지 않습니다.
- 음악은 기본적으로 없습니다. 에필로그·크레딧에만 절제된 음을 검토합니다. 퍼즐의 막힘을 음악으로 압박하지 않습니다.

### 믹싱 시작 규칙

평상시 환경음을 기준으로 손잡이·시험 피드백이 분명히 들리게 편집합니다. 최대 음량과 갑작스러운 스팅어로 놀라게 하지 않습니다. 같은 큐의 여러 표현을 겹칠 때 합산 음량을 보정합니다. 중요한 결과음 동안 환경음은 짧게 낮출 수 있으나 완전 무음 후 폭발음은 없습니다.

P05는 실제 물의 원인 위치와 청음구 방사 위치를 구별해 제작합니다. 단순히 잘못된 방향에서 파일 하나를 틀지 않습니다. 차단·개방에 따른 변화와 유량 표시가 같은 입력 상태를 공유해야 합니다. 청각 단서 시각화도 방사 위치와 펄스를 표시하며 정답 노선 이름을 바로 알려 주지 않습니다.

발소리는 걷기·달리기·재질에만 반응합니다. 플레이어가 멈추면 발소리도 멈춥니다. 존재 없는 공포를 만들기 위해 뒤따르는 타인의 보폭을 재생하지 않습니다. 긴 잔향은 공간의 잔향임을 들을 수 있어야 합니다.

## 6. 화면 효과·접근성

- 2000년대 초 디지털카메라 같은 약한 색 바램을 출발점으로 합니다. 저해상도 자체가 단서 판독을 방해하면 효과를 낮춥니다.
- 그레인·비네팅·색 번짐은 약하게, 각각 끌 수 있게 합니다. 모션 블러·공포 전용 카메라 흔들림은 없습니다.
- 물속의 착색·흐림은 개구부 모서리와 표식 판독을 보존합니다. 강한 굴절은 기능 단서에 쓰지 않습니다.
- 깜빡임을 끈 설정에서도 동일한 정보가 지속 조명·기계 반응으로 남아야 합니다. 힌트는 깜빡임에만 의존하지 않습니다.
- 모든 기능색은 모양·무늬·위치와 중복됩니다. 붉은 REC도 아이콘·스위치 자세가 함께 있습니다.
- 자막형 소리 설명은 ‘금속음’처럼 출처 사실을 전달하며 “정답은 B”라는 해설이 아닙니다.
- FOV와 화면비가 달라도 P08 촬영 범위 판정은 장치 카메라의 고정 광학 기준을 씁니다. 플레이어 화면을 넓히는 설정이 정답을 바꾸면 안 됩니다.

## 7. 에셋과 제작 단위

기본 조립 격자 0.5 m, 일반 텍스처 밀도 256 px/m를 시작값으로 씁니다. 가까이 비교할 흠집·눈금·화면은 더 높은 해상도로 제작합니다. 미터 규격은 레벨별 논리 관계를 방해하면 조정하며, 판이 발판 높이에 맞는 등 기능 관계는 유지합니다.

| 묶음 | 필수 에셋 | 우선 재사용 |
|---|---|---|
| 주차장 | 벽·기둥·승강 팔레트·피트·덮개판·릴·접속 틀·셔터 | 현재 주차장 재질·벽·기둥·표지판 |
| 수영장 | 두 수조·부표·밸브·배관·유량 바늘·부력대·도크 | 공통 손잡이·점검 틀·난간 |
| 학교 | 복도·문·책상·시험등·차광판·모니터·점검 카메라 | 접속 틀·상태 표시·스프링 문 |
| 귀환 | 새 장소 키트보다 배선·감지선·전실 | 주차장·학교 장치·케이블 |

범용 물리 로프·유체·실시간 무한 반사·캐릭터·생물 애니메이션은 에셋 계획에 없습니다. 연출 전용 배경 변형은 충돌과 해법 상태를 갖지 않으며 필수 증거처럼 꾸미지 않습니다.

외부 재질·음원·글꼴은 사용 조건이 명확한 자료만 쓰고 출처·라이선스·가공 내역·다운로드 날짜를 자산 목록에 남깁니다. 이 문서 작업에서 새 외부 에셋을 내려받거나 라이선스를 확보한 것은 아닙니다. 이번에는 문서 검토만 하며 화면·음량·접근성의 실제 확인은 별도 사용자 테스트 계획에 둡니다.
