# 아트 · 사운드 가이드

> 목표: 적은 인원으로 만들 수 있으면서, 리미널 스페이스의 "익숙한데 이상한" 느낌이 나는 것.

## 1. 전체 방향

**한 문장:** 2000년쯤 찍은 디지털카메라 사진 같은 화면.

| 하는 것 | 하지 않는 것 |
|---|---|
| 평평하고 고른 형광등 빛 | 극적인 명암, 손전등 |
| 깨끗하게 비어 있는 공간 | 피, 낙서, 폐허 같은 파손 |
| 조금 낮은 해상도의 실사풍 재질 | 만화풍, 과한 사실감 |
| 같은 부품의 반복 | 방마다 다른 소품을 잔뜩 배치 |
| 사람의 흔적 (놓고 간 물건) | 사람, 동물, 형체 |

**"비어 있음"이 곧 스타일이다.** 소품이 적을수록 좋으므로, 2인 개발에 유리하다. 대신 남겨 둔 소품 하나하나는 공들여 만든다.

## 2. 화면 효과

| 효과 | 값 |
|---|---|
| 필름 그레인 | 약하게 (설정에서 끌 수 있음) |
| 색 번짐 (화면 가장자리) | 아주 약하게 |
| 안개 | 장소마다 색이 다른 옅은 안개. 먼 곳이 살짝 뿌옇게 |
| 블룸 | 형광등과 비상구 등 주변에만 약하게 |
| 모션 블러 | 없음 |
| 화면 비네팅 | 약하게 |
| 톤 | 살짝 바랜 색, 대비 낮음 |

## 4. 규격과 조립 부품

**격자:** 모든 부품은 0.5 m 격자에 맞춘다. 벽 높이는 장소별 규격(레벨 명세의 공통 규격 표)을 따른다.

**텍스처 밀도:** 1 m에 256픽셀. 일부러 조금 낮게 잡는다 (옛 디지털카메라 느낌 + 작업량 감소). 플레이어가 가까이 보는 소품(흔적, 표지판)만 512.

**재질:** 색, 거칠기, 노멀 세 장. 금속이 거의 없으므로 금속 맵은 대부분 생략.

### 부품 목록

| 묶음 | 부품 | 개수 (대략) |
|---|---|---|
| 주차장 | 바닥판, 벽, 기둥, 경사로, 천장(배관 포함), 형광등, 차단봉, 방화셔터, 주차 턱, 표지판 6종, 엘리베이터, 관리실 | 25 |
| 차 | 승용차 3종 × 색 4개, 흰 승용차(특별) | 4 |
| 상가 | 바닥 타일 2종, 셔터 가게 전면, 간판 8종, 수영용품점 내부 | 15 |
| 수영장 | 풀 3종(메인, 작은, 유아), 타일 재질 15종, 벽, 천장 트러스, 레인 줄, 출발대, 사다리, 다이빙 타워, 미끄럼틀, 밸브, 배관, 관람석, 벽시계 | 35 |

**합계 약 150개 남짓.** 사람과 생물이 없어 캐릭터 작업이 전혀 없다.

### 간판과 글자
- 간판, 표지판, 게시물은 직접 만든다. 실제 상표나 실제 학교 이름을 쓰지 않는다.
- 글꼴은 상업적으로 쓸 수 있는 무료 글꼴만 쓴다 (사용 조건을 확인하고 목록을 남긴다).

## 5. 외부 자료 사용 원칙

- **CC0(조건 없이 쓸 수 있는) 자료를 우선** 쓴다. 예: Poly Haven(재질, 하늘), ambientCG(재질).
- 내려받은 자료는 `assets/_licenses/` 폴더의 표에 **출처, 사용 조건, 내려받은 날짜**를 적는다. Steam 출시 때 이 표가 필요하다.
- 조건이 불분명한 자료는 쓰지 않는다.
- 도구: Blender(모델), Krita 또는 GIMP(텍스처), Material Maker(재질), Audacity(소리).

## 6. 사운드

### 방향
- **음악은 거의 없다.** 소리의 주인공은 공간이다.
- 조용할수록 작은 소리가 크게 들린다. 소리의 개수를 늘리지 말고 하나하나를 또렷하게.
- 퍼즐 단서가 되는 소리는 **항상 같은 소리**를 쓴다 (플레이어가 소리를 배운다).

### 소리 묶음 (오디오 버스)
```
Master
├─ Ambience   (공간 소리, 장소별로 서서히 섞음)
├─ SFX        (발소리, 문, 물, 변화음)
│   └─ Reverb (장소별 울림: 주차장 길고 어둡게, 수영장 길고 밝게, 학교 짧게)
├─ Cue        (퍼즐 단서 소리, 다른 소리에 묻히지 않게 따로)
└─ UI
```

### 장소별 환경음
| 장소 | 바탕 | 가끔 나는 소리 |
|---|---|---|
| 주차장 | 형광등 웅웅, 환기구 낮은 바람 | 먼 곳의 물방울, 금속 팽창 "틱", 아주 먼 차 소리 |
| 상가 | 형광등, 멀리서 물 흐르는 소리 | 셔터 떨림, 냉장고 모터 |
| 수영장 | 물 찰랑, 넓은 울림, 여과기 | 물방울, 배관 꿀럭, 레인 줄 부딪힘 |
| 탈의실·체육관 | 샤워기 똑똑, 마루 삐걱 | 멀리서 공 튀는 듯한 울림 |
| 학교 | 거의 무음, 창밖 바람, 시계 초침 | 형광등 안정기 소리, 먼 문 닫힘, 수도관 |
| 4장 | 주차장 + 얕은 물 찰랑 | 1~3장의 소리가 가끔 섞여 들림 |
| 에필로그 | 새소리, 먼 도로, 첫 버스 | |

### 효과음 목록
| 분류 | 소리 |
|---|---|
| 발소리 | 콘크리트, 타일(마른/젖은), 얕은 물, 마루, 인조석, 철계단 × 각 6개 변형 |
| 물 | 입수, 잠수 중(저역 필터), 떠오름, 뛰어듦(높은 곳) |
| 문·장치 | 철문, 나무 문, 스프링 문, 셔터, 엘리베이터(문, 이동, 도착음), 밸브(돌리기, 딸깍), 버튼, 서랍 |
| 규칙 단서 | R1 반복됨(아주 낮은 "웅"), R2 이어짐(물속 울림), R3 바뀜(끌리는 소리, 딸깍) |
| 힌트 | 형광등 깜빡임 소리, 물방울, 금속 울림 |
| 기타 | 흔적 발견(작은 종이 소리), 저장(무음) |

### 음악
- 딱 세 곳에만 쓴다: 2-7 다이빙 타워 꼭대기(긴 패드 한 음), 4-6 출구(아주 조용한 피아노 몇 음), 에필로그와 크레딧.
- 나머지는 음악 없이 환경음만.

### 소리 자료 출처
- 직접 녹음을 우선한다 (실제 지하 주차장, 수영장, 학교 복도는 녹음하기 쉽다. 녹음 전 허락을 받는다).
- 외부 자료는 5장의 원칙과 같다: 조건이 분명한 것만, 표에 기록.

## 7. 작업 순서

1. **그레이박스 단계에서는 아트를 입히지 않는다.** 회색 상자와 임시 화살표만.
2. 1장 버티컬 슬라이스(M2)에서 화면 효과, 주차장 부품, 소리 체계를 한 번 끝까지 만들어 기준을 세운다.
3. 이후 장은 그레이박스가 확정된 것부터 아트를 입힌다 (퍼즐이 바뀌면 아트를 버려야 하므로).
4. 조명 굽기는 장별 아트가 끝난 뒤 한 번에.
