## 2. 기둥과 금지 사항

**세 기둥** (결정이 애매할 때 이 세 가지에 비춰 고른다)
1. **조용한 위화감**: 익숙한 장소가 조금 틀어져 있다. 놀래키지 않는다.
2. **관찰하면 풀린다**: 필요한 정보는 전부 공간 안에 있다. 반응 속도나 손재주는 필요 없다.
3. **규칙은 정직하다**: 랜덤이 없다. 같은 행동은 항상 같은 결과를 낸다.

**하지 않는 것**
- 도구, 인벤토리, 전투, 적, 사망, 시간 제한
- 대사, 내레이션, 설명 문구, 튜토리얼 팝업
- 화면이 번쩍이거나 잘리는 전환 연출
- 언어를 알아야 풀 수 있는 단서 (7장 참고)

## 3. 플레이어 동작

| 동작 | 입력 | 수치 |
|---|---|---|
| 걷기 | WASD | 3.2 m/s |
| 천천히 걷기 | Shift | 1.6 m/s, 발소리 작아짐 |
| 둘러보기 | 마우스 | 기본 시야각 75도 (60~100 조절) |
| 상호작용 | E | 닿는 거리 2.0 m. 대상에 작은 점 표시 |
| 점프 | Space | 높이 0.5 m. 낮은 턱 넘기, 물에 뛰어들기 |
| 웅크리기 | Ctrl | 눈높이 1.6 m → 1.0 m. 물에서는 잠수 |
| 물 위 이동 | WASD | 1.8 m/s. 수영 조작은 따로 없고 수면에 떠서 이동 |

- 달리기는 없다. 대신 기본 걷기가 조금 빠르다.
- 낙하 피해가 없다. 어디서 떨어져도 그냥 착지한다.
- 뒷걸음질 속도는 앞으로 걷는 속도와 같다 (3장, 4장에서 뒷걸음질이 중요하다).

## 4. 세 가지 규칙의 정확한 정의

퍼즐 설계와 구현은 모두 이 정의를 따른다. 정의와 어긋나는 퍼즐은 만들지 않는다.

### R1. 주차장: 화살표를 따르면 제자리, 거스르면 다음

- 주차장은 **구간**으로 나뉘고, 구간의 경계마다 보이지 않는 **관문**이 있다. 모든 관문에는 방향이 있다 (바닥 화살표, 문의 "입구" 표지, 차가 향한 방향으로 드러난다).
- 관문을 **정방향**으로 지나면 → 같은 구간의 처음으로 돌아온다 (반복).
- 관문을 **역방향**으로 지나면 → 다음 구간으로 나온다 (진행).
- 플레이어가 느끼는 규칙: "온 길로 되돌아가야 나아간다."

| 경우 | 처리 |
|---|---|
| 관문 위에서 멈추거나 왔다 갔다 함 | 관문 면을 완전히 통과한 순간의 이동 방향만 본다 |
| 뒷걸음질로 통과 | 몸이 향한 쪽이 아니라 **이동 방향**으로 판정한다 |
| 이전 구간으로 돌아가기 | 불가. 진행은 한 방향이다 (1-6만 예외로 층을 오르내린다) |
| 예외 장치 | 1-6의 연결 통로, 1-8의 엘리베이터는 각 퍼즐 명세에 따로 정의 |

### R2. 수영장: 바닥 타일이 같은 물끼리 이어진다

- 물이 찬 곳의 바닥에는 **타일 구역**이 있다. 타일은 색과 무늬의 조합으로 구분한다 (예: 파랑 줄무늬).
- 머리까지 잠긴 채 1초가 지나면 → **같은 타일**을 가진 다른 물에서 떠오른다. 양방향이다.
- 같은 타일을 가진 물은 **항상 정확히 두 곳**이다 (설계자가 보장한다).
- 물이 없거나 너무 얕으면(1.0 m 미만) 이어지지 않는다.
- 플레이어가 느끼는 규칙: "같은 타일의 물은 하나의 물이다."

| 경우 | 처리 |
|---|---|
| 한 수영장에 타일 구역이 둘 | 잠수한 위치 바로 아래의 타일로 판정 |
| 짝이 되는 물이 비어 있음 | 이어지지 않는다. 잠수해도 그 자리에서 떠오른다 |
| 반쯤 찬 물 (1.0 m 이상) | 이어진다 |
| 떠오르는 위치 | 짝 타일 구역의 정해진 지점. 항상 같은 곳 |
| 색을 구분하기 어려운 플레이어 | 모든 타일은 색 말고도 무늬가 다르다. 물가 벽에 같은 무늬의 큰 표식이 붙어 있다 |

### R3. 학교: 보지 않는 것은 바뀐다

- 바뀔 수 있는 대상을 **변이체**라고 부른다. 변이체마다 **정해진 순서의 상태 목록**이 있다 (예: 벽돌 → 창고 → 복도 → 다시 벽돌).
- 변이체는 **"보는 중"에서 "안 보는 중"으로 바뀔 때마다** 다음 상태로 한 칸 넘어간다.
- **보는 중** = 화면 안에 대상의 일부가 들어와 있고, 벽 같은 것에 완전히 가려지지 않은 상태.
- 유리나 거울에 비친 모습, 켜진 CCTV 모니터 화면으로 보는 것도 "보는 중"이다.
- 3-8부터: **녹화 중인 CCTV 카메라가 찍고 있는 곳**은 플레이어가 안 봐도 "보는 중"으로 친다 (카메라의 빨간 불로 표시).
- 플레이어가 느끼는 규칙: "보고 있으면 그대로, 눈을 떼면 다음으로."

| 경우 | 처리 |
|---|---|
| 화면 가장자리에 걸침 | 플레이어에게 유리하게, 화면보다 조금 넓은 범위까지 "보는 중"으로 친다 |
| 아주 잠깐 시야에서 벗어남 | 0.5초 이상 벗어나야 "안 보는 중"이 된다 |
| 한 번도 본 적 없는 변이체 | 첫 상태 그대로다 (본 적이 있어야 넘어간다) |
| 바뀌는 순간 | 절대 화면에 보이지 않는다. 소리만 작게 난다 (끌리는 소리, 딸깍) |
| 플레이어가 변이체 안에 서 있음 | 그 변이체는 바뀌지 않는다 (끼임 방지) |

### 규칙의 겹침 (4장)
- R1 관문, R2 타일, R3 변이체가 한 공간에 함께 있다. 서로의 정의는 바꾸지 않는다.
- 예: R1 관문의 화살표가 R3 변이체일 수 있다 (안 보는 사이 화살표 방향이 바뀐다).

## 5. 변화가 갑작스럽지 않게 만드는 원칙

1. **하나의 건물.** 무대는 1998년에 열고 2009년에 닫은 신도시의 "새솔 복합센터". 실제 건물의 동선대로 이어진다.
   ```
   [지하 주차장] ─ [지하 연결 상가] ─ [스포츠센터 수영장] ─ [탈의실·체육관] ─ [새솔초등학교]
         ▲                                                                   │
         └──────────────────── (학교 지하 기계실) ────────────────────────────┘
   ```
2. **사이 구간.** 장과 장 사이 20분 동안 다음 장소가 **소리 → 색 → 물질 → 규칙** 순서로 스며든다.
3. **변화 강도 4단계.** 각 장은 1단계에서 시작하고 4단계는 장 후반에만 쓴다.

   | 단계 | 바뀌는 것 | 예 |
   |---|---|---|
   | 1 | 작은 디테일 | 표지판 숫자, 게시물 한 장 |
   | 2 | 물건 | 차의 방향, 의자 위치 |
   | 3 | 방의 구조 | 문의 행선지, 복도 길이 |
   | 4 | 공간 전체 | 다른 층, 다른 건물 |

4. **바뀌는 순간은 보여주지 않는다.** 변화는 문 너머, 물속, 모퉁이 뒤, 등 뒤에서만 일어난다.
5. **앵커 오브젝트.** 반복되는 공간에는 늘 같은 자리에 있는 물건을 둔다. 플레이어가 "여기가 아까 거기"임을 아는 기준이다.

   | 장 | 앵커 |
   |---|---|
   | 1장 | 쓰러진 커피컵, 흰 승용차, 기둥 번호 |
   | 2장 | 노란 킥판, 9시 40분에 멈춘 벽시계, 물가의 타일 표식 |
   | 3장 | 빨간 실내화 한 켤레, 초록 비상구 표시등, 교실 번호판 |

## 6. 전체 구성과 페이싱

| 구간 | 장소 | 규칙 | 퍼즐 | 시간 | 난이도 (1~5) |
|---|---|---|---|---|---|
| 프롤로그 | 주차장 입구 | 없음 | 0 | 10분 | 0 |
| 1장 | 지하 주차장 | R1 | 8 | 45분 | 1 → 3 |
| 사이 A | 지하 연결 상가 | R1 약해짐, 물 등장 | 3 | 20분 | 1 |
| 2장 | 스포츠센터 수영장 | R2 | 9 | 50분 | 1 → 4 |
| 사이 B | 탈의실·체육관 | 물 사라짐, 시선 등장 | 3 | 20분 | 1 |
| 3장 | 새솔초등학교 | R3 | 10 | 55분 | 2 → 4 |
| 4장 | 돌아온 주차장 | R1+R2+R3 | 6 | 35분 | 3 → 5 |
| 에필로그 | 정문 | 없음 | 0 | 5분 | 0 |
| **합계** | | | **39** | **약 4시간** | |

**각 장 안의 흐름** (모든 장이 같은 틀을 따른다)
1. **발견** (퍼즐 1~2개): 규칙을 스스로 알아챈다. 실패해도 잃는 게 없다.
2. **확인** (2~3개): 같은 규칙이 다른 모습으로 나온다. "역시 그렇구나."
3. **응용** (2~3개): 규칙으로 계획을 세워야 한다.
4. **뒤집기** (1~2개): 규칙의 뜻밖의 면을 보여준다. 장의 절정.

**리듬:** 어려운 퍼즐 뒤에는 퍼즐 없이 걷기만 하는 30초~1분의 긴 복도나 넓은 공간을 둔다. 숨 돌리는 구간이자 분위기 구간이다.

## 7. 단서 설계 규칙

퍼즐마다 아래를 지킨다. 레벨 명세의 "단서" 항목이 이 규칙을 만족하는지 확인한다.

1. **단서는 세 겹으로 준다.**
   - 눈: 화살표, 색, 반복되는 물건
   - 귀: 가까워질수록 달라지는 소리, 변할 때 나는 작은 소리
   - 배치: 조명이 단서를 비추고, 통로의 모양이 시선을 단서 쪽으로 이끈다
2. **언어에 기대지 않는다.** 퍼즐에 필요한 정보는 숫자, 화살표, 색, 무늬, 그림으로만 전한다. 한글 간판은 분위기용이고 읽지 못해도 풀 수 있어야 한다.
3. **틀려도 정보를 얻는다.** 잘못된 시도는 벌이 아니라 단서가 된다 (같은 커피컵이 또 나온다 = 반복 중이라는 정보).
4. **규칙을 처음 보여주는 퍼즐은 실수로도 풀리게 한다.** 헤매다 우연히 풀고 "어, 왜 됐지?" 하고 되짚는 경험이 설명문보다 낫다.
5. **한 퍼즐에 새 요소는 하나만.**

## 8. 힌트 시스템

화면에 글자를 띄우지 않고, 공간이 조금씩 더 눈에 띄게 알려준다.

| 머문 시간 | 일어나는 일 |
|---|---|
| 7분 | 핵심 단서 위의 형광등이 천천히 깜빡인다 |
| 12분 | 단서 쪽에서 작은 소리가 난다 (물방울, 금속 울림) |
| 18분 | 해법의 첫 동작을 암시하는 변화가 생긴다 (퍼즐마다 명세에 적는다) |

- 머문 시간은 퍼즐 방 안에 있는 동안만 센다. 일시정지 중에는 세지 않는다.
- 설정에서 "힌트 끄기 / 기본 / 빠르게(시간 절반)"를 고를 수 있다.

## 9. 스토리와 수집 요소

### 스토리 (환경으로만)
- 같은 아이의 이름 **"한결"**이 장소마다 남아 있다. 플레이어가 한결인지는 끝까지 밝히지 않는다.
- 주제: **어릴 적에 다니던 곳은 기억 속에서 조금씩 틀어져 있다.** 공간의 규칙은 기억이 왜곡되는 방식을 닮았다.
  - 주차장(R1): 같은 기억을 자꾸 되풀이한다. 되짚어 가야 다음이 떠오른다.
  - 수영장(R2): 비슷한 기억끼리 이어져 섞인다.
  - 학교(R3): 들여다보지 않는 기억은 바뀐다.
- 에필로그: 이른 아침, 정문에 "철거 예정" 현수막. 설명은 없다.

### 흔적 (수집 요소 12개)
찾지 않아도 클리어할 수 있다. 메뉴의 "흔적" 화면에 찾은 것이 사진처럼 쌓인다. Steam 도전 과제와 연결한다.

| 4 | A-2 수영용품점 | 이름표가 붙은 수영모 |
| 5 | 2-4 막다른 방 | 수영 강습 출석부 (한결: 화·목반) |
| 6 | 2-6 막다른 방 | "한결"이라고 쓰인 노란 킥판 |
| 7 | 2-7 다이빙 타워 | 관람석에 놓인 식은 보온병과 수건 |
| 8 | B-2 사물함 | 한 짝뿐인 어린이 슬리퍼 |
| 9 | 3-1 게시판 | "우리 가족" 그림 (네 명 중 한 명이 지워짐) |
| 10 | 3-8 방송실 | 점심 방송 신청곡 쪽지 |
| 11 | 3-9 도서관 | 대출 카드 (같은 책을 일곱 번 빌림) |
| 12 | 4-5 흰 승용차 | 뒷좌석의 어린이 카시트 |

- 12개를 모두 찾으면 에필로그에서 현수막 대신 다른 장면이 하나 더 나온다 (정문 유리에 비친 플레이어의 모습이 어린아이의 키다).

## 10. 화면, 메뉴, 설정, 접근성

### 화면
- 플레이 중 화면에는 아무것도 없다. 상호작용할 수 있는 대상에 가까이 가면 작은 점만 나온다.
- 저장 중일 때 구석에 작은 아이콘이 1초 표시된다.

### 메뉴
- **메인 메뉴:** 이어하기 / 새로 시작 / 흔적 / 설정 / 종료. 배경은 현재 저장 위치의 정지 화면.
- **일시정지:** 계속 / 이 방 다시 시작 / 설정 / 메인 메뉴로.
- "이 방 다시 시작"은 현재 퍼즐 방을 처음 상태로 되돌린다. 막힘을 푸는 최후의 수단이다.

### 설정
| 분류 | 항목 |
|---|---|
| 조작 | 마우스 감도, 상하 반전, 키 변경, 컨트롤러 지원 |
| 화면 | 해상도, 창 모드, 수직 동기화, 품질(낮음/보통/높음), 시야각, 밝기 |
| 소리 | 전체/환경음/효과음 음량 |
| 편의 | 힌트(끄기/기본/빠르게), 걸을 때 화면 흔들림 끄기, 화면 중앙 점 표시, 필름 그레인 끄기 |
| 접근성 | 소리 단서 시각화(소리가 난 방향에 옅은 물결 표시), 색각 보조(타일 무늬 대비 강화), 웅크리기·천천히 걷기 토글 방식 |

### 접근성 원칙
- 소리로만 주는 단서는 없다. 모든 소리 단서에는 눈으로 볼 수 있는 짝이 있다.
- 색으로만 구분하는 것은 없다. 색에는 항상 무늬나 모양이 함께 간다.
- 멀미 줄이기: 화면 흔들림 끄기, 시야각 조절, 중앙 점 표시, 모션 블러 없음.

### 언어
- 메뉴는 한국어와 영어. 게임 속 간판은 한국어 그대로 둔다 (배경이 한국이고, 퍼즐 단서는 언어와 무관하다).

## 11. 저장

- 퍼즐 방에 들어설 때, 그리고 퍼즐을 풀었을 때 자동 저장. 수동 저장은 없다.
- 저장 슬롯 3개.
- 저장 내용: 현재 위치, 풀린 퍼즐 목록, 각 퍼즐 방의 상태(밸브 위치, 변이체 상태 등), 찾은 흔적, 설정.
- 이어하기를 하면 마지막 저장 지점의 방 입구에서 시작한다.

## 12. 성공 기준 (테스트로 확인할 것)

| 목표 | 기준 |
|---|---|
| 규칙이 스스로 발견된다 | 테스터 80% 이상이 각 장 첫 퍼즐을 힌트 2단계 전에 푼다 |
| 막힘이 길지 않다 | 한 퍼즐 20분 이상 막히는 경우가 테스터 1명당 1번 이하 |
| 끝까지 한다 | 테스터 70% 이상이 4장까지 도달한다 |
| 분량 | 첫 플레이 중간값 3.5~4.5시간 |
| 분위기 | "무섭다"보다 "이상하고 조용하다"는 반응이 많다 |
