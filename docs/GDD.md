# 새솔센터 게임 기획서 v2 — 상황을 이해해서 빠져나가는 공포

> 2026-11-12 · PC · Godot 4 · 2인 개발 가정
> **새 기획이며 현재 게임에 구현됐다는 뜻이 아닙니다.** 구현 현황은 [TECH.md](TECH.md), 조사 근거는 [RESEARCH.md](RESEARCH.md)를 봅니다.

## 1. 선결론

문 닫은 한국 복합센터에서, **보이는 공간과 실제로 연결된 공간이 다르다는 사실을 실험으로 확인하고 출구까지 이어지는 동선을 만든다.**

퍼즐마다 해결할 상황이 먼저입니다. 돌아가기·잠수·고개 돌리기는 가능한 행동일 뿐, 장별 공식이나 보편적인 정답이 아닙니다. 기존 39개 퍼즐과 R1/R2/R3의 정의는 폐기합니다. 주차장·수영장·학교, 공간과 기억의 어긋남이라는 발상만 남깁니다.

중심 재미는 **관찰 → 서로 다른 가설 → 구별할 수 있는 실험 → 발견 → 계획 → 실행**입니다. 규칙을 안 뒤 같은 행동을 여러 번 해야 하는 시간을 재미로 계산하지 않습니다.

### 확정 조건

- 싱글플레이 1인칭 탐색. 전투·적·추격·사망·점프 스케어·반응 속도 시험·숨 참기 제한이 없습니다.
- 사람·동물·괴물·인체 실루엣·가짜 추격자도 등장시키지 않습니다. 빈 화면 뒤에 갑자기 얼굴을 띄우지 않습니다.
- 시간 제한·랜덤 정답·실패 시 장 전체 초기화가 없습니다. 천천히 생각해도 불이익이 없습니다.
- 새솔 복합센터의 1998년 개관·2009년 폐관 설정을 유지합니다. 실제 시설명을 사용하지 않습니다.
- 플레이타임을 먼저 고정하지 않습니다. 아래 **11개 핵심 상황**은 서로 다른 발견을 담기 위한 현재 설계이며 출시 개수나 분량 보장이 아닙니다.

## 2. 공포와 퍼즐의 관계

**이해한 작동 방식은 믿을 수 있지만, 이런 공간이 왜 존재하는지는 끝까지 확신할 수 없습니다.**

모든 정보를 의심하게 만들지는 않습니다. 표지판의 방 이름·겉보기 거리·녹화 화면은 검증할 수 있는 주장입니다. 직접 수행한 실험의 인과관계·장치의 작동 표시·확보한 안전 동선은 믿을 수 있습니다. 같은 조건에서 같은 결과가 나옵니다.

| 불안의 재료 | 경험 | 정직함을 지키는 방법 |
|---|---|---|
| 공간의 수가 맞지 않음 | 떨어진 피트들에 같은 팔레트가 있음 | 한 번 조작하면 앞뒤 피트가 동시에 반쯤 떠 있는 것을 확인 |
| 거리와 소리가 맞지 않음 | 가장 가까이 들리는 소리가 실제 배수 지점과 다름 | 차단 실험과 기계식 표시로 검증 |
| 기록과 현재가 다름 | 화면의 시험등이 실제 입력에 반응하지 않음 | 입력을 바꿔 정보의 최신성 확인 |
| 아는 장소의 관계가 달라짐 | 익숙한 주차장에 배선과 통행을 함께 유지해야 함 | 이미 익힌 계약으로 해결 |

정답 직전 사물 바꾸기, 의미 없는 낙서 변형, 뒤따르는 발소리로 실제 적을 약속하기, UI·설정·저장 오류 흉내, 갑작스러운 암전·최대 음량은 사용하지 않습니다. 공포가 풀리지 않는 퍼즐의 변명이 되면 안 됩니다.

## 3. 재사용하는 공간 문법

세 문법은 제작자가 조합할 재료입니다. 장별로 하나씩 배당하지 않습니다. **모든 문·물·시선에 적용되는 법칙도 아닙니다.** 정상 장치와 이상 현상을 구별할 증거를 먼저 제공합니다.

### J — 접속과 동일성

다른 위치의 개구부나 물체가 하나의 연결·상태를 공유할 수 있습니다. 연결 개구부는 고정된 짝과 좌표 대응을 가집니다. 같은 물체의 두 표현은 하나의 실제 상태를 공유합니다. 비슷한 외형만으로 연결을 판단하지 않습니다.

- 용접 흠집·레일 눈금 같은 개체 특징과 조작의 동시 반응으로 동일성을 증명합니다.
- 통과 방향·전진/후진·몸의 방향은 행선지를 바꾸지 않습니다. 되돌아가야 항상 진행하는 계약은 없습니다.
- 변경 가능한 연결은 노선 표시와 접속 틀로 현재 상태를 확인할 수 있습니다.
- 통행·빛·배선·수중 운반 중 무엇이 통과 가능한지는 해당 장치 명세에 명시합니다. 증거 없이 임의로 확장하지 않습니다.

### C — 환경의 연동

문짝·수위·부력대·배수관의 원인과 결과를 이용합니다. 물은 특별한 타일을 밟으면 이동하는 시스템이 아닙니다. 길·운반 수단·높이 기준·연결의 증거로 다르게 사용합니다.

- 수위와 밸브 상태는 눈으로 확인합니다. 물리 공식이나 미세한 손 조절을 요구하지 않습니다.
- 조작은 정해진 정지점에 맞습니다. 던지기·균형 잡기·임의 물리 적층을 요구하지 않습니다.
- 환경음은 공간의 결과입니다. 큰 소리가 무조건 목표 위치를 뜻하지 않습니다.

### O — 관측과 기록

실시간 영상·보관 화면·직접 관찰은 같은 정보가 아닙니다. 시험등·차광판으로 검증할 수 있습니다.

- **고개를 돌리는 행위 자체는 상태 변경 명령이 아닙니다.** 시야 밖 상태 순환은 없습니다.
- 후반 고정 장치는 REC가 켜진 실제 카메라가 지정 구조 구역을 포착할 때만 그 구조를 유지합니다. 화면을 쳐다보기만 해서는 고정되지 않습니다.
- 구조 변경은 별도 손잡이로 요청합니다. 카메라는 요청 중 자기 구역을 유지합니다.
- 사람·물·플레이어·일반 물리 현상을 영상으로 정지시키지 않습니다. 고정 가능한 구조 경계가 점검선으로 드러납니다.
- 보관 화면에는 고정 능력이 없습니다. 장치의 실제 작동 표시는 거짓말하지 않습니다.

## 4. 전체 진행

```text
프롤로그: 정상적인 거리·설비·소리 익히기
  ↓
주차장 P01 동일성 실험 → P02 동선과 조작 순서 → P03 연결의 길이
  ↓ 연결 상가: 물과 배관 예고, 별도 퍼즐 없음
수영장 P04 연동 분리 → P05 전달 경로 분리 → P06 수중 운반
  ↓ 탈의실·체육관: 화면과 실제 시험등의 차이 예고
학교 P07 정보 최신성 → P08 선택적 구조 유지 → P09 중복된 방의 회로
  ↓
귀환 P10 배선과 통행 동시 유지 → P11 중복 신호를 바로잡고 퇴장
  ↓
에필로그: 일상 소리와 정문, 해설 독백 없음
```

P04~P06은 독립된 문제입니다. P04 해법을 세 번 반복하지 않습니다. P07·P09는 고정 장치 사용을 요구하지 않습니다. P10의 필수 선행 지식은 P03·P08, P11은 P01·P07·P09입니다.

### 사고·행동·발견·감정 비교표

| ID / 상황 | 주된 사고 | 핵심 행동 | 새 발견 | 감정 변화 |
|---|---|---|---|---|
| P01 겹친 빈자리 | 같은 모양과 같은 개체 구분 | 2호기 한 칸 조작·앞뒤 피트 비교 | 떨어진 표현이 상태를 공유 | 익숙함 → 불가능성 |

| P07 멈춘 화면의 시험등 | 정보 최신성·좌우 대응 검증 | 시험등·차광판으로 화면 비교 | 선명한 화면도 현재는 아닐 수 있음 | 안도 → 기록에 대한 의심 |
| P08 남겨 둘 복도 | 유지할 부분 선택 | 촬영 범위·REC·구조 변경 | 목표 대신 필요한 길을 남김 | 관찰 → 능동적인 편집 |
| P09 두 이름의 교실 | 이름 수와 개체 수 분리 | 차단기 반응 대조·회로 차단 | 접근점 둘이 별개 방은 아님 | 익숙함 → 기억의 중복 |
| P10 길과 전선은 다르게 | 다른 경로의 지속 조건 결합 | 접속부 고정 후 구조 전환 | 지난 뒤에도 배선 연결이 필요 | 성취 → 건물 전체의 모순 |
| P11 마지막 퇴장 | 사건 기록과 실제 경계 구분 | 시험 펄스·중복 채널 묶기 | 숫자 대신 중복 측정을 고침 | 의심 → 확인한 해방 |

프롤로그는 정산소·차단기·비상 개방 손잡이로 정상 동작과 조작을 익힙니다. 주차권을 읽거나 특정 곳을 바라봐야 문이 열리는 조건은 없습니다. 처음의 건너편 인도와 정문이 에필로그의 비교 기준입니다. 연결 상가·탈의실은 다음 장소의 재질과 정보 형식을 예고하고 분량 확보용 소형 퍼즐을 넣지 않습니다. 탐색할 정보가 없다면 이동 길이를 줄입니다.

## 5. 퍼즐 제작 계약

레벨 명세가 구현 기준입니다. 명세에 없는 예외를 코드로 보충하지 않습니다.

1. 목표와 장애물이 먼저 보여야 합니다. 이유 없는 장치 조작부터 시키지 않습니다.
2. 적어도 두 가설과 구별 실험이 있어야 합니다. 버튼을 전부 누르는 일만 남으면 재설계합니다.
3. 실패는 관찰 가능한 정보를 남깁니다. 이유 없는 리셋은 없습니다.
4. 소리·색·언어 한 가지만 알아야 하는 문제는 없습니다.
5. 다른 풀이를 행동 순서 검사로 막지 않습니다. 실제 상태·통행 가능성으로 완료 판정합니다.
6. 해법을 알면 불필요한 반복이 없어야 합니다. 먼 왕복을 난이도로 세지 않습니다.
7. 이상 현상은 개체 특징·반응·접속 틀로 확인하며 외형이 같은 모든 문에 일반화하지 않습니다.

고정 손잡이·릴·슬롯·점검용 부력대를 씁니다. 도구 인벤토리·열쇠 찾기·소모품·수집 개수로 진행을 잠그지 않습니다. 메모 없이 비교할 수 있게 두 증거 사이 동선을 짧게 합니다.

## 6. 페이싱과 서사

정상 기준 → 국소적 모순 → 통제 가능한 실험 → 공간적 결과 → 조용한 재해석을 기본으로 하되 횟수와 장면을 반복하지 않습니다. 퍼즐 난도와 연출 강도를 항상 함께 올리지 않습니다.

- 주차장: 분리된 설비가 하나로 반응하며 공간의 수를 의심합니다.
- 수영장: 물과 소리가 연결을 드러내지만 거리 감각은 맞지 않습니다.
- 학교: 기록은 남아 있지만 현재를 보장하지 않습니다.
- 귀환: 플레이어가 공간과 기록의 불일치를 고치며 해결감을 얻습니다.

주제는 **한 장소를 여러 시기의 이름과 동선으로 기억하는 일**입니다. 필수 물증은 개관 안내도·폐관 점검 배선도·현재 철거 예고입니다. 서로 다른 자료가 같은 건물을 다르게 나눈다는 사실이 퍼즐과 이어집니다. 아이 사망·범죄·정신질환을 반전 정답으로 지정하지 않습니다. 한결이라는 이름은 선택적 흔적에만 남기고 플레이어와 동일하다고 확정하지 않습니다.

추가 흔적은 해석을 풍부하게 할 뿐 필수 정답을 숨기지 않습니다. 전부 모아야 보는 결말을 없앱니다. 클리어하면 반드시 에필로그를 봅니다.

## 7. 조작·접근성·힌트

WASD 이동, 마우스 시점, E 상호작용, Ctrl 웅크리기/수중 내려가기, Space 낮은 턱 넘기/수면 복귀, Shift 달리기, Esc 일시정지를 기준으로 합니다. 달리기·점프·잠수 숙련을 필수 해법으로 요구하지 않습니다. 현재 조작 수치와 새 목표는 기술 문서에서 구분합니다.

- 구조 고정은 REC 장치가 담당합니다. FOV나 고개 각도 유지 시험이 없습니다.
- P06은 수중 이동 대신 점검 운반 핸들로 같은 경로를 조작할 수 있습니다. 인과 추론은 동일합니다.
- 색에 무늬·모양·위치를 함께 줍니다. 소리 단서는 물결·눈금·가동부로도 확인합니다.
- 밝기 설정과 품질 옵션으로 정답 증거가 사라지지 않게 합니다. 흔들림·그레인·색 번짐·깜빡임을 끌 수 있습니다.
- 메뉴는 한국어·영어, 필수 판단은 그림·기계 반응·공간 관계로 가능합니다.

### 힌트

고정 7/12/18분 대신 **새 증거·의미 있는 상태 변화 없이 3분/6분/9분**에 단계가 올라갑니다. 실제 새 관찰·실험은 정체 시간만 초기화하고 이미 나온 단계는 유지합니다. 반복 클릭은 진전이 아니며 일시정지·설정 화면에서는 시간을 멈춥니다.

1단계는 볼 곳, 2단계는 정보 관계, 3단계는 다음 실험·첫 행동을 제안합니다. 장치를 대신 조작하지 않습니다. 설정은 끄기/기본/빠르게(대기 절반), 요청형 전체 도움은 일시정지 메뉴의 선택 사항입니다. 레벨 명세에 구체 내용을 둡니다.

## 8. 상태·저장·검증

ID는 `v2_p01`~`v2_p11`이며 기존 구현 ID와 재사용하지 않습니다. 방 입구와 안정된 조작 완료 시 저장하고 전환 중 저장은 안정 상태로 정규화합니다. 자동 저장·이어하기·현재 상황 초기화는 향후 요구사항입니다. 초기화는 현재 퍼즐만 되돌리고 이전 완료·흔적을 유지합니다. 낙하·끼임 복구는 몸만 안전 발판으로 옮기며 장치 상태와 정보를 지우지 않습니다.

구체적 설계가 재미와 공포를 입증하지는 않습니다. 검증할 가설과 관찰표는 [PRODUCTION.md](PRODUCTION.md)에 있습니다. **이번 문서 작업에서 게임 실행·빌드·자동 테스트·플레이 테스트는 하지 않습니다.**
